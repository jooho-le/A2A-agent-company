# 앱 시작 스플래시

- 앱 진입 시 약 4초 동안 표시한다. 3.6초에 페이드아웃을 시작해 4초에 오피스 조작을 허용한다. 메뉴 이동·로그인 복귀에는 다시 표시하지 않으며 새로고침하면 다시 시작한다.
- 배경 #030407, 파란색 #1558C9, 라임색 #D4FF24를 유지한다. `design/DESIGN.md`의 큰 타이포그래피와 검은 전시 공간 구성을 참고해 실제 3D 오피스가 드러나는 오프닝으로 구성했다.
- 검은 문 두 장이 입체적으로 열리고, 실제 오피스의 확대·기울기·초점이 천천히 제자리로 돌아온다. “아이디어 하나로, 당신만의 회사.” 문구와 다섯 역할의 직원 이미지가 순서대로 나타난다. 마지막에는 환영 문구가 지나가고 글라스 메뉴·업무 패널·직원 상태 표시가 들어온다.
- 실제 서비스의 기존 3D 오피스를 그대로 보여준다. 추가 영상·이미지·3D 라이브러리나 별도 렌더러는 생성하지 않았다. 다른 메뉴 주소로 직접 진입한 경우에는 기존 오피스 배경 이미지로 연출하며 목적 화면을 유지한다.
- App과 오피스는 뒤에서 한 번만 마운트해 준비한다. 스플래시가 닫혀도 화면을 다시 마운트하지 않는다. 표시 중에는 inert로 배경 조작을 막고 오피스의 시각 모션을 대기한다. 서버 업무 처리는 멈추지 않는다.
- 건너뛰기 버튼과 Escape로 즉시 들어갈 수 있다. 종료 후 타이머로 재등장하지 않는다. 모션 줄이기 설정에서는 문 열기·확대·텍스트 이동 없이 정적인 화면을 표시한다.
- 진행선은 브랜드 연출이며 서버 준비·에이전트 작업 진행률이 아니다. 실제 Run 생성이나 API 호출을 추가하지 않았다.

## 확인

실제 Chrome에서 약 4초 뒤 자동 전환, 뒤에서 준비된 오피스, 메뉴 이동 시 미재등장, 모바일 건너뛰기, Escape, 모션 줄이기를 확인했다. 데스크톱·모바일·작은 가로 화면에 넘침이나 런타임 예외가 없었다. 기존 프론트 테스트 195개 및 빌드·코드 검사를 통과했다. 기존 3D 번들 용량 안내는 남아 있다.

백엔드·인증·업무 접수·A2A 계약은 변경하지 않았다. Git commit/push는 수행하지 않았다.
