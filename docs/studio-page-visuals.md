# 서브 페이지의 입체감과 움직임 보강

## 바뀐 화면

- **직원 소개**: `팀은 어떻게 일하나요?`를 데스크톱 최대 64px, 모바일 32~37px 제목으로 키웠다. 펼치면 팀장·기획·개발·품질·보안 역할을 카드뉴스처럼 넘겨본다. 기존 직원 상세 버튼과 협업 구조 안내는 유지한다.
- **내 프로젝트**: 입체 폴더와 실제 프로젝트 수를 표시하는 패널, 색이 다른 프로젝트 카드를 추가했다. 조회 중이거나 조회에 실패해 개수를 알 수 없으면 숫자를 단정하지 않는다.
- **진행 상황**: 실제 조회된 직원 상태를 큰 인물 카드로 보여준다. 작업 중인 직원만 움직임과 점 표시로 강조한다. 역할 소개의 순서를 실제 실행 순서로 표현하지 않는다.
- **결과물**: 문서·코드에 맞는 입체 표지와 옆으로 넘기는 카드를 추가했다. 결과 정보와 펼쳐보는 상세 내용은 그대로다.
- **전자문서**: 종이 오브젝트가 있는 제목 패널을 추가했다. 업로드·목록·다운로드 처리와 인증은 변경하지 않는다.

## 표현과 조작

- 배경 `#030407`, 요청창 `#1558C9`, 주요 버튼·선택 메뉴 `#D4FF24`를 유지한다. 보라·초록·살구·금색은 카드 구분에 사용한다.
- 프로젝트·결과물은 버튼, 터치 스크롤, 키보드로 탐색한다. 카드가 자동으로 넘어가지 않으며 기존 버튼과 펼친 내용은 유지된다.
- 역할 소개는 좌우 버튼·직원 선택 점으로 넘긴다. 슬라이드 영역에 초점이 있으면 방향키로도 넘긴다. 실제 작업 진행 화면과 구분한다.
- 포인터 기울임, 오브젝트 부유, 카드 등장 효과는 표시 효과다. 추가 WebGL 장면이나 외부 애니메이션 라이브러리는 사용하지 않는다.
- 화면 설정의 `움직임 끄기`와 운영체제의 모션 줄이기를 반영한다. 터치에서는 포인터 기울임을 적용하지 않는다.

## 구현 위치

- `frontend/src/StudioEffects.css`: 페이지 패널, 카드, 입체 오브젝트, 반응형·모션 규칙.
- `StudioVisuals.jsx`: 장식 오브젝트, 페이지 패널, 카드 목록 탐색.
- `TeamStoryDeck.jsx`: 수동 역할 소개 슬라이드.
- `useStudioMotion.js`: 현재 페이지의 카드 등장·포인터 효과와 정리 처리.
- 기존 화면 컴포넌트에는 시각 요소만 연결했다. 백엔드·프로토콜·실행 판정·접수 계약은 변경하지 않았다.

## 확인 범위

- 기존 프론트 테스트 **197개**, 빌드, ESLint를 통과했다. 기존 3D 장면의 큰 번들 경고는 남아 있다.
- 격리된 Chrome에서 프로젝트 선택, 결과물 목록·카드 이동, 역할 소개, 모바일 390px·320px 배치를 확인했다. 모바일에서 카드가 압축되는 문제를 고쳐 실제 카드 폭과 터치 이동까지 점검했다.
- 마우스 기울임, 화면 설정의 모션 끄기, 운영체제 모션 줄이기를 확인했다. 전자문서 화면도 1440px·390px·320px에서 가로 넘침과 런타임 예외가 없었다.
- 화면 점검의 로그인·프로젝트·작업 응답은 브라우저 안에서만 대체한다. 실제 계정·작업·문서 생성이나 유료 모델 실행은 하지 않는다.
- 메인 오피스와 중앙 팝업형 로그인은 유지한다. 기존 서비스 서버는 종료하지 않는다.
