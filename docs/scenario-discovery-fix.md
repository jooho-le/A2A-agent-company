# 작업 시작 정보 조회 오류 수정

- 화면의 `시나리오`는 실행할 수 있는 작업 종류다. 현재 제품은 등록된 회원가입 시나리오를 사용한다.
- 조사 당시 제품 서버, Host, Agent 4개의 응답은 정상이었다. Host에도 회원가입 시나리오 1개가 등록되어 있었다.
- 제품 서버는 Host의 JSON 문자열 ID를 UUID 객체로 저장된 등록 키와 비교해 정상 시나리오를 빈 목록으로 걸러냈다. 프론트는 이 목록으로 실행 설정을 확인할 수 없어 시작을 차단했다.
- `backend/project_scenarios.py`에서 문자열·UUID를 같은 UUID 키로 정규화했다. 미등록 ID와 잘못된 값은 계속 차단한다. 인증이나 승인 설정 검증을 우회하지 않는다.
- API 테스트는 HTTP 200뿐 아니라 실제 시나리오 목록도 확인하도록 보강했다. 문자열·UUID 일치와 미등록 값 차단 테스트를 추가했다.
- 백엔드 테스트 83개 통과. 실제 Host를 조회하는 제품 코드에서 시나리오 1개와 승인된 MULTI_AGENT 설정을 확인했다. 유료 모델 호출이나 새 작업 생성은 하지 않았다.
- 사용자 승인 후 제품 서버(8000)를 정상 재시작해 수정본을 적용했다. 프론트·제품·Host·Agent 4개의 응답과 인증 없는 요청 차단을 확인했다. 화면의 `다시 연결`로 시작 정보를 다시 조회하면 된다.
