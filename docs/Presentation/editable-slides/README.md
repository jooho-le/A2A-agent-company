# AIO 발표자료 페이지별 편집

현재 통합 발표자료의 **PDF 출력 순서 1~28장**을 `01`~`28` 폴더로 나눴다. 폴더 번호는 과거 입력 자료인 `presentation.pdf`의 페이지 번호가 아니라, 현재 발표자료를 PDF로 출력했을 때의 번호다.

## 수정할 파일

| 파일 | 바꾸는 내용 |
| --- | --- |
| `01/index.html`~`28/index.html` | **화면에 실제 나오는** 문구·숫자·표·이미지. `[화면 글자]` 주석 아래를 수정 |
| 각 폴더의 `notes.html` | 발표자만 보는 메모. 여기의 글자는 장표 본문에 나오지 않음 |
| 각 폴더의 `style.css` | 해당 페이지만의 색상·글자 크기·여백·위치·개별 요소 스타일 |
| `shared/global.css` | 모든 페이지가 공유하는 기본 디자인. 공통 변경이 필요할 때만 수정 |
| `shared/assets/` | 기존 캐릭터·배경 이미지. 페이지마다 복사하지 않고 공유 |
| `manifest.json` | PDF 출력 순서와 페이지 폴더 목록 |
| `shared/template.html` | 통합 HTML의 메뉴·전체 보기·발표 노트·인쇄·기존 상세 근거 등 공통 기능 |

각 페이지의 `index.html`은 **편집 원본이자 직접 열어 볼 수 있는 미리보기**다. 별도 서버나 빌드 없이 열 수 있다. 텍스트를 수정하고 브라우저를 새로고침하면 된다.

## 한 페이지 수정하기

예: 23페이지를 고칠 때 `23/index.html`과 `23/style.css`만 수정한다.

1. `index.html`에서 **`[화면 글자`를 검색**한다. `큰 제목`, `설명 문구`, `표 항목`, `명찰` 등으로 표시한 주석 바로 아래의 태그 사이 글자를 수정한다. `AIO:SLIDE:START`~`AIO:SLIDE:END` 표시와 장표를 감싸는 `section`은 유지한다.
2. `style.css` 맨 위 색상표와 제목 크기·위치 변수를 조정한다. 아래쪽에는 기존 개별 요소의 색상·스타일을 옮겨 놓았다.
3. 추가 배치는 파일 아래의 **페이지 전용 추가 스타일** 영역에 적는다. 해당 페이지의 `data-editable-page` 선택자를 유지하면 다른 페이지에 영향을 주지 않는다.
4. `data-title`은 **전체 목록·탐색용 제목**이다. 여기를 바꿔도 화면의 큰 제목은 바뀌지 않는다. 큰 제목은 `[화면 글자 … | 큰 제목]` 아래의 `h1` 또는 `h2` 안에서 수정한다. 필요하면 `data-title`도 함께 맞춘다.

### 저장했는데 글자가 그대로일 때

- 개별 파일 `editable-slides/01/index.html`을 보고 있다면 해당 페이지의 `[화면 글자]` 아래 문구를 수정하고 저장·새로고침한다.
- `capstone-presentation-draft.html`을 보고 있다면 **통합본**이다. 아래 통합 명령을 실행한 뒤 새로고침한다.
- `notes.html`의 글자는 발표 메모다. 장표 본문과 별도로 유지한다.
- `<title>`은 브라우저 탭 이름, `data-title`은 전체 목록 제목이다. 둘 다 화면 본문이 아니다.
- `미리보기 설정`, `상단·하단 도구`, `공통 아이콘` 영역은 장표 문구가 아니다. 모든 `index.html`에서 주석으로 구분했다.

예를 들어 제목을 오른쪽으로 20px 옮기려면 해당 `style.css`의 `--page-title-offset`을 `20px 0px`로 변경한다. 특정 카드의 간격을 바꿀 때는 페이지 전용 추가 스타일 영역에서 그 카드의 클래스를 지정한다.

이미지를 교체할 때는 해당 페이지 폴더에 PNG·JPG·SVG 등을 넣고 `index.html`의 `img src="새이미지.png"` 또는 `style.css`의 `url("새이미지.png")`로 참조한다. 통합 시 이미지·폰트는 HTML 안에 삽입되므로 통합 HTML 하나로 전달할 수 있다.

## 전체 HTML로 합치기

프로젝트 루트에서 실행한다. Python 3.10 이상만 필요하며 외부 패키지·서버·API 호출은 없다.

```sh
python3 docs/Presentation/editable-slides/build.py
```

출력 파일은 기존과 같은 `docs/Presentation/capstone-presentation-draft.html`이다. 이후부터는 **페이지 폴더를 원본으로 수정**한다. 통합 HTML을 직접 수정한 내용은 다음 통합 시 덮어써진다.

기존 파일을 덮어쓰지 않고 다른 이름으로 출력하려면 다음과 같이 실행한다.

```sh
python3 docs/Presentation/editable-slides/build.py --output /private/tmp/aio-preview.html
```

파일 누락·필수 표시·이미지 경로만 확인하려면 다음을 실행한다. 파일을 변경하지 않는다.

```sh
python3 docs/Presentation/editable-slides/build.py --check
```

## PDF로 출력하기

- **전체 28장:** 통합 HTML을 Chrome에서 열고 상단 `PDF 인쇄` → 대상 `PDF로 저장`. CSS가 1600×900 비율과 페이지 나눔을 적용한다. 배경 그래픽을 켜고 머리글·바닥글은 끈다.
- **한 장만:** 해당 폴더의 `index.html`을 열고 `이 페이지만 PDF`를 누른다.
- 인쇄는 텍스트·표를 포함한 HTML을 출력한다. 화면을 캡처해서 PDF에 붙이는 방식이 아니다.

23페이지에 가격·API 원가 내용을 합친 뒤 중복된 기존25페이지를 삭제했다. 현재 총28장이며, 기존26~29페이지는25~28페이지로 이동했다. 기존 이미지·발표·인쇄 기능과 과거 PDF 상세 근거는 보존했다. 페이지 미리보기의 `이전 PDF`는 해당 과거 PDF 위치를 열고, 전체 발표자료에서는 기존처럼 상세 근거 창을 연다.
