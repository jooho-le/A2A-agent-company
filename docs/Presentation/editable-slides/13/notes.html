실험에서 확인하려는 두 효과

첫째는 동일한 검증 피드백 아래에서 Single과 Multi의 수정·재검증 결과가 달라지는가다. Ver1의 두 구조는 공통 보호시험 결과와 실패 근거를 받는다. 둘째는 별도 공통 피드백 없이 직접 시험을 만들고 수행할 때 역할 분리의 효과가 나타나는가다. Ver2의 Single·Multi도 자체 QA·Security 시험은 수행한다.

네 조건은 같은 모델·요구사항·시작 코드·예산과 개발 중 공개하지 않는 동일한 최종 9개 시험을 사용하도록 설계한다. Ver1과 Ver2의 차이를 보려면 Agent 구조를 고정하고 비교하며, 구조 효과를 보려면 Ver를 고정한다. 피드백 정책과 Agent 구조를 동시에 바꾸어 원인을 단정하지 않는다.

11·12페이지의 숫자가 뜻하는 범위

현재 11·12페이지는 실제 측정 데이터가 아니라 발표 표 구성을 위해 만든 ‘조건별 10회 가정 비교 예시’다. 이 페이지의 결론도 해당 예시표를 산술적으로 해석한 것이다. 실제 멀티 에이전트 성능이나 보호시험의 효과가 입증되었다고 제시하지 않는다. 원본 실측의 실패·ERROR·HUMAN_REVIEW를 예시표의 통과율로 바꾸어 해석하지 않는다.

같은 Ver에서 Single → Multi

Ver1의 최종 전체 통과율은 60→80%, Ver2는 50→70%이므로 모두 +20%p다. 통과건 평균 판정 시간은 350→290초,390→330초로 각각60초 짧다. 평균 모델 비용은0.15→0.13달러로 약13.3%,0.17→0.14달러로 약17.6% 낮다. 평균 수정은1.8→1.2회,2.2→1.6회로 각각0.6회 적다.

같은 Agent 구조에서 Ver2 → Ver1

Single의 전체 통과율은50→60%, Multi는70→80%로 각각 +10%p다. 통과건 평균 판정 시간은390→350초,330→290초로 각각40초 짧다. 평균 모델 비용은0.17→0.15달러로 약11.8%,0.14→0.13달러로 약7.1% 낮다. 평균 수정은2.2→1.8회,1.6→1.2회로 각각0.4회 적다.

발표할 때 구분할 점

퍼센트포인트(%p)는 통과율의 차이이며 상대 개선율(%)과 다르다. 비용 감소율은 비교 전 비용을 분모로 계산했다. 표의 시간은 통과한 제품들만의 평균이고, 모델 비용·수정 횟수는 가정한 전체10회 평균이다. 통과한 제품 수와 구성도 달라 전체 실행의 속도 향상이나 인과 효과로 단정할 수 없다. 모델 비용은 Sandbox·인프라·사람 검수 등 전체 비용이 아니다. 실제 우위·유의성·효과 크기는 동일 조건 반복 실측과 실패 포함 기록으로 확인해야 한다.
