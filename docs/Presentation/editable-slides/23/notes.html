23페이지와 기존25페이지를 합친 가격·모델 비용 설명

노션 v08 §8~10에 따라 협업 구독 정책, 모델별 API 단가, 역할별 모델 라우팅, 가상 토큰 비용 계산을 연결했다. 혼합모델의 품질·속도·절감률을 실제 호출로 측정했다는 뜻은 아니다. 중복된 기존25페이지는 삭제하고 고객ROI·시장·GTM·마무리 장표를25~28페이지로 앞당겼다.

요금: Start49,000원/월(3명·2프로젝트·내부 실행원가 예산18,000원), Team129,000원(6명·8프로젝트·45,000원), Studio299,000원(12명·20프로젝트·110,000원)은 WTP 실험 가설이다. 플랫폼의 가시화·수정·승인·변경 이력 가치와 팀 규모를 기준으로 한 제안이며 정확한 금액을 확정한 실결제 표본은 없다. 예산은 환급금·제작 횟수 보장이 아니다. 한도 안에서 반복 업무를 진행하고 초과 사용은 금액·상한을 안내해 사전 승인받는다. 직접 실행원가1.8배는 추가 사용료의 내부 실험안이다.

공식 단가 확인: 2026-11-25 확인한 모델 페이지 기준 Standard 일반 입력/출력100만 토큰당 Luna$0.10/$0.50, Terra$1/$5, Sol$2/$10이다. 캐시·Batch/Flex·지역 및 긴 문맥 할증 등을 적용하지 않는 예시다. 누적 토큰은 여러 일반 요청에 나누어 사용한 가정으로, 단계의 토큰 합계 전체를 한 번의 긴 요청에 보낸다는 뜻은 아니다.

가정한 역할별 비용: PM입력100,000·출력10,000을 Luna로 계산하면0.1×0.1+0.01×0.5=$0.015. Developer450,000/80,000을 Terra로 계산하면0.45×1+0.08×5=$0.850. QA·보안 요약150,000/20,000을 Luna로 계산하면0.15×0.1+0.02×0.5=$0.025. 어려운 수정250,000/40,000을 Sol로 계산하면0.25×2+0.04×10=$0.900. 합계입력950,000·출력150,000, 비용$1.790이다. 동일 토큰량 전체를 Sol로 계산하면0.95×2+0.15×10=$3.400이다.

환율1USD=1,400원을 가정해 혼합2,506원·모두Sol4,760원, 차이2,254원이다. 감소율(3.400−1.790)/3.400×100=47.3529…%로47.4%다. 실제 모델별 토큰량·실패율·품질이 같다는 증거는 없으며 Sandbox·테스트·재시도·지원·검수비도 포함하지 않았다. 따라서 실측 성과·고객 절감률·실제 이익률로 쓰지 않는다. 가격정책 실험과 별개인 API비 계산 시나리오다.

25페이지의 원가 통제 원칙: 요약·보고는 저비용 모델과 템플릿, 일반 구현은 중간 성능 모델, 어려운 오류는 고성능 승격. QA는 실제 테스트, 보안은 정적분석을 우선하고 LLM은 해석·보고에 사용한다. 실패 파일·로그 중심 전달과 변경 영향 범위 재검증, 반복 실패·예산 상한으로 불필요한 호출을 제한한다. 실제 수익성은 동일 품질에서 도구·재시도·사람 검수와 지원을 포함한 전체 비용p50/p90, 공헌이익으로 판단한다.

기존 월 예산 검산은 Start49,000−18,000=31,000원(63.3%), Team129,000−45,000=84,000원(65.1%), Studio299,000−110,000=189,000원(63.2%)이다. 실행 예산 전량 사용 가정이며 사람 검수·지원·결제·세금·서버·영업·온보딩·CAC는 미차감했다.
