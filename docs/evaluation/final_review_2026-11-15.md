# SCN-001 최종 코드·실행 준비 점검

2026-11-15. 평가 담당 코드와 Host/Single/Multi 연결 경로를 검토하고 저장소의 `tests`·`checks` 전체를 실행했다. **유료 모델 호출과 실제 비교 실험은 0회**다. 기존 작업을 보존했고 커밋·푸시하지 않았다.

## 완료 범위

- PyCharm `Multi Host`에 내부 인증 토큰 4개를 추가했다. `Single Host` 구성과 토큰 1개도 준비했다. 기존 API 키를 유지했으며 값은 출력하거나 문서에 넣지 않았다. 두 구성은 Git 제외 로컬 설정이며 현재 명령은 `--start` 없는 설정 점검용이다.
- 두 구성의 `--check-secrets` 결과가 `OWNED_HOST_CONFIGURATION_VALID` / `PRESENT`다. 이는 값의 존재·형식 검사이며 OpenAI 원격 인증 성공을 뜻하지 않는다.
- 임시 DB에서 Single/Multi × Ver1/Ver2 Host를 실제로 기동했다. 모든 Agent의 health 응답, 토큰 없는 요청 거부(401), 올바른 토큰을 사용한 요청의 인증 통과(형식 오류 400), 종료 후 포트 해제를 확인했다. OpenAI 어댑터의 전송은 차단했고 전송 시도도 0회였다. 기존 사용자 Run은 제출·수정하지 않았다.
- 공통 시작 커밋 `e6e7158c356ff0be5ffa12ec59894d2217f61ca8`, 공통 이미지 `sha256:c712fdf445fe01217001440459070bf1e2b0a8d94ad3b9103bacfedddf7dae5a`를 유지했다. 최종 Ver1·Ver2 사전 검사 모두 `ready=true`이며 실제 브라우저 실행과 정리 검사도 포함한다.
- 현행 시험 묶음은 **0.5.2**, 공식 최종 SHA-256은 `dff9e3b5ee543b819c5326306529ae522db05d3b2380497f0809287fa557f624`다. Ver1 보호 파일·참조·인계 지문과 시험지 문서를 함께 갱신했다.

전체 검사는 수정 작업 전에 시작했다. 최초 실패는 `test_real_docker_confirms_regression_with_two_replays_per_version`의 `REPLAY_CONDITIONS_DIFFER_OR_INPUTS_INCOMPLETE`였다. 해당 검사에서 저장한 입력 기록의 시험 버전은 0.5.1이었고 검사 도중 작업 트리가 0.5.2로 바뀌었다. 원본 입력 기록의 **메타데이터만** 읽어 시험 지문 불일치와 하네스 지문 일치를 확인했다. 보호 장치가 다른 시험지의 기록 재생을 거부한 것이며 이 검증을 완화하지 않았다. 수정 완료 후 새 기록으로 실행한 Docker 10개 묶음에는 이 검사가 포함되며 모두 통과했다.

진행 중 점 출력 위치로 실패를 시간초과 검사라고 추정했지만, 최종 JUnit에서 위 재생 검사로 확인해 정정했다. 시간초과 검사 개선은 별도의 테스트 안정성 보완이다. 전체 검사 이후 소스 변경 범위를 대조했고 변경 영향 범위를 별도로 재검사했다. **최종 코드로 전체 5,635개를 다시 한 번 실행했다고 표시하지 않는다.** 위 검사 묶음은 겹치는 항목이 있으므로 수를 합산하지 않는다. 현재 재검사에서 남은 실패는 없다.
