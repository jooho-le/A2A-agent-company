# QA·Security 세부 결과 기능 최종 검증 — 2026-11-15

## 결과

최종 코드의 전체 테스트 **5,735개 통과, 실패 0, 오류 0, 건너뜀 0**. `tests`와 `checks`에서 수집한 전체 검사를 중복 없는 두 묶음(2,446개 / 3,289개)으로 실행했다. 각 묶음은 별도 임시 폴더와 캐시를 사용했다. 중단한 이전 실행과 추가 확인 테스트를 이 합계에 넣지 않았다.

실행 로그에는 경고 965건이 기록됐다. 기존 도구 클래스 `TestReportTools`를 테스트 클래스로 수집하지 않는다는 경고와, 테스트의 `VersionedTaskStore`에 event stream이 없어 복제본 간 스트리밍이 꺼진다는 경고다. 위 통과 수에는 실제로 수집·실행한 테스트만 포함했다.

실제 로컬 Docker 평가 통합 검사 9개도 모두 통과했다. 전체 실행 전후 Python 파일 532개의 해시가 같았으며 코드가 실행 중 변경되지 않았다. Python 3.10.2와 3.13.16에서 보호 시험 파일 8개의 전달 내용이 동일하고 원본과 AST가 같음을 별도로 확인했다. Host 설정은 61,418바이트로 기존 64 KiB 제한과 4 KiB 여유분 검사를 충족한다.

실제 싱글·멀티 비교 실험은 실행하지 않았다. 전체 테스트 프로세스에는 모델 제공자 API 자격정보를 상속하지 않았다. 테스트용 예제·대역과 로컬 Docker 검증 결과이며, 실제 모델이 생성한 회원가입 코드의 성능 측정 결과는 아니다.

`summary.md`에서 상세표로 이동할 수 있다. 이전 Snapshot도 채점하면 `version_details/vN/`에 각 버전의 상세표를 저장한다. 다시 채점할 때 이전 상세표가 섞이지 않도록 기존 결과 교체 절차를 사용한다.
