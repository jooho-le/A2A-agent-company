관측 콜백 합계 중앙값 30.82ms. 기록된 일부 계측 비용일 뿐 전체 부가 비용은 아닙니다. 순수 네트워크 시간처럼 빼서 해석하지 않습니다.

측정 시계

같은 프로세스의 perf_counter_ns()를 사용합니다. 분산 서버 시계 오차나 운영 네트워크 SLA 검증은 범위 밖입니다.

준비에는 fixture·payload 생성, 직렬화에는 JSON/protobuf 변환과 전송 전 준비가 포함됩니다. 결과 관측에는 게시·DB 저장·20ms 폴링·결과 역직렬화가 포함됩니다. 무응답의 미관측 시간은 0으로 채우지 않습니다. 파일의 20MiB 정책과 HTTP JSON 본문의 64KiB 진단 한도는 별개의 제한입니다.
