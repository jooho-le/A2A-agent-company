# 오피스 레이아웃·글라스 조정

- **입력창 잘림**: 부모의 overflow: clip과 바깥쪽 outline-offset: 5px !important가 포커스 테두리를 잘랐다. 오피스 요청 폼의 overflow를 해제하고 입력창 안쪽에 2px 포커스를 표시한다. 필드 폭도 패널 내부로 제한한다.
- **메뉴 전환 시 위치 변화**: workspace-shell을 모든 대시보드 메뉴가 공유한다. 사이드바·상단바의 위치, 폭, 패딩을 공통화하고 내용만 내부에서 스크롤한다. 메뉴를 바꾸면 내용 스크롤을 맨 위로 복원한다.
- **투명 글라스**: 주 패널 배경 알파를 데스크톱 28%, 모바일 38%로 낮추고 블러·얇은 경계를 사용한다. 직원 라벨과 작업 상태 패널도 반투명하게 조정했다. 기존 파란색·라임색과 상태별 강조는 유지한다.

## 확인

- 1440×900에서 오피스·프로젝트·직원·업무 흐름·보관함의 사이드바/상단바/메뉴 버튼 좌표가 동일하다. 사이드바는 위·아래 20px 여백을 유지한다.
- 1024×768, 760×900, 390×844에서 가로 넘침과 입력창 잘림 없음. 모바일 메뉴 전환 후에도 같은 위치를 유지한다.
- 실제 브라우저에서 요청창의 포커스·3D 재진입을 확인했다. 테스트 응답으로 인증된 메뉴를 확인했으며 실제 AI 업무는 생성하지 않았다.
- 기존 프론트 테스트 195개 통과. 프로덕션 빌드 성공. 기존 3D 번들 용량 경고는 남아 있다.

백엔드·업무 접수·Run·Trace 데이터 처리 로직과 design/DESIGN.md는 변경하지 않았다. Git commit/push는 수행하지 않았다.
